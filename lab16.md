# Лабораторна робота №16: Збереження даних користувача та робота з Web Storage API

**Виконав:** Студент інтернет-магазину "TechShop"  
**Мета:** Опанувати роботу з механізмами Web Storage API (localStorage, sessionStorage), навчитися робити серіалізацію через JSON і налаштувати синхронізацію стану між різними вкладками браузера.

## Що було реалізовано у проєкті:
1. **Перемикач Dark/Light теми** — додано кнопку у шапку сайту. Вибір користувача зберігається у `localStorage`. Для запобігання блимання білого екрана (артефакт FOUC) в `<head>` вбудовано швидкий inline-скрипт перевірки теми.
2. **Довготривала пам'ять кошика покупок** — масив `cart` автоматично конвертується у рядок JSON за допомогою `JSON.stringify()` і зберігається в локальному сховищі при будь-яких діях користувача. При завантаженні сторінки стан відновлюється через `JSON.parse()` всередині безпечних блоків `try...catch`.
3. **Персистентність списку "Улюблене"** — товари, які користувач перетягнув за допомогою Drag-and-Drop API, зберігають свої ID в `localStorage`, тому список обраного не зникає після оновлення сторінки (F5).
4. **Автозбереження чернетки форми** — дані полів оформлення замовлення (ПІБ, телефон, пошта) автоматично записуються в `sessionStorage` по події `input` і надійно очищуються лише після успішного натискання на сабміт "Підтвердити замовлення".
5. **Міжвкладочна синхронізація** — додано слухач події `window.addEventListener('storage')`, завдяки якому при зміні теми або додаванні товарів в одній вкладці, сусідня вкладка цього ж браузера миттєво оновлює свій інтерфейс без перезавантаження сторінки.
